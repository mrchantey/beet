# About Beetmania

Beetmania is a fan site with no code: every page is a markup file, served by [beet](https://beet.org). How it works, from the entrypoint down:

1. [The files](/about/files): the three things every beet site needs.
2. [Routing](/about/routing): how files become pages.
3. [Layouts](/about/layouts): the document template wrapping every page.
4. [Styling](/about/styling): named rules and one-off inline styles.
